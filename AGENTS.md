# Sign-O-Matic: agent notes

- Local web app + `signo` CLI for 47x70mm shelf signs. Stack: Hono API, Vite/React UI, pdf-lib, sharp, zod.
- **No real branding anywhere in the repo.** Sample brands are fake and generated by `scripts/make-fake-logos.ts`. Real data goes in gitignored `data/`.
- One renderer: `src/core/layout.ts` (pure geometry) + `src/core/pdf.ts`. The UI preview is the PDF rendered with pdf.js; never fork a second renderer.
- Batch state is `data/batch.json`, shared by CLI and UI (UI polls every 2.5s).
- Gates (check exit codes, never pipe through tail): `pnpm typecheck`, `pnpm test`, `pnpm build`.
- pnpm 11 age gate: after any `pnpm add`, check pnpm-workspace.yaml; never bypass minimumReleaseAge.
- Ports: API 7047, Vite dev 7048.
- UI = shadcn/ui (style base-nova, Base UI primitives: use `render=` not `asChild`; ToggleGroup value is an array; Select needs `items`). Components live in web/src/components/ui; add more with `pnpm dlx shadcn@latest add <name>`. components.json + vite.config.ts are at the repo root (Vite `root` is web/) so the CLI detects the framework. Registry output imports `cn` from the "cn" package; this repo rewrites it to `@/lib/utils`, so re-check after any `add`.
- Theme tokens (warm paper + orange primary) are in web/src/styles.css; no hand-written component CSS.
- Sheet geometry (`src/core/geometry.ts`) is shared by pdf.ts and the web overlay (SheetView); change cell math in one place only.
- Undo lives in web/src/useBatch.ts (snapshot stack). Toast "Undo" only undoes its own change (checks the top entry id).
- Logo scale is capped by `maxLogoScale(aspect)` (layout.ts); slider max + CLI both use it, so the control never silently does nothing.
- Background removal backs up to data/logos/originals/<id>.png; a fresh upload deletes the backup.
- Browser e2e lives outside the repo for now (Playwright from the Hermes install); run it against `pnpm start` with a fresh `data/`.
- Templates: `src/core/template.ts` is the single layout engine (PDF, designer canvas, checks). The designer measures text in the browser with Carlito via canvas (`web/src/designer/measure.ts`); keep fonts identical to the PDF's embedded ones or the canvas will lie.
- Built-in template ids `percent`/`price` can't be deleted; signs whose template is missing fall back to them. `Sign.templateId` is optional (old batches still load).
- Template-set import: same id + same layout = skipped; same design under another id = skipped ("as <id>"); otherwise keep-both (renamed copy) or replace.
- base-nova `AlertDialogAction` is a plain Button: it does NOT close the dialog. Close it yourself in onClick.
- Designer keyboard shortcuts are window-level and only active on the Templates tab; App's Ctrl+Z/Ctrl+P only on Make signs.
- Theme = Nord (web/src/styles.css). Use the --nordN variables/semantic tokens, never raw colours. Three contrast-tuned shades (--nord10-deep, --nord11-deep/-light, --nord12-deep) keep text at WCAG AA. The printed sign is always black on white paper; on-paper overlays (SignCanvas) use --nord10 directly, not --primary (which is light in dark mode). Light/system/dark toggle lives in web/src/theme.ts (localStorage signo.theme).
